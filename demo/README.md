# Demo

Sahnede asıl demo **canlı** yapılacak (7 dk sunum + 3 dk soru-cevap, sıra kura ile anlık okunuyor — hazırlanma süresi yok). Bu klasördeki içerik iki amaca hizmet eder:

1. **AI Jüri kanıtı** — AI Jüri kodu okur, uygulamayı çalıştırmaz; ekran görüntüsü olmadan ürünü hiç "görmez".
2. **Canlı demo yedeği** — internet/ortam sorunu çıkarsa gösterilecek ekran kaydı.

Deploy zorunlu değil (bkz. README > Deploy URL ve Bilinen Sınırlar) — yerel çalışan bir ürün yeterli, önemli olan sahnede çalıştırabilmek.

## İçerik
- `screenshot-01.png`, `screenshot-02.png`, ... — ana ekranların/akışların görüntüleri, canlı demo'daki sırayla numaralandırılmış
- `screen-recording.mp4` veya video linki — **opsiyonel yedek**, canlı demo çökerse diye

## Notlar
- Ekran görüntülerini kısa dosya adlarıyla ve akış sırasına göre numaralandırarak ekleyin.
- Her görüntünün altına README'de kısa bir açıklama satırı ekleyin.
- En çarpıcı çıktı (X-Factor'ün göründüğü an) ilk 2-3 görüntüde olmalı — jüri hızlı bakar.
